# v0.21: rename the plugin to deliver

Status: approved by the user on 2026-09-04 ("rename it to deliver, that's how the codex rewrite will
be called too"). Writing standard: `plugins/poteto/skills/unslop/SKILL.md`.

## Purpose

`pm-skill` becomes `deliver`: the marketplace, the plugin, its directory, its command namespace, its
hook and runner messages, and its documentation. The name of the thing users install and type
changes; the state a project already carries does not.

## A. What changes

| Surface | Before | After |
|---|---|---|
| Marketplace name (`.claude-plugin/marketplace.json`) | `pm-skill` | `deliver` |
| Plugin name and directory | `pm-skill`, `plugins/pm-skill/` | `deliver`, `plugins/deliver/` |
| Command namespace | `/pm-skill:<cmd>` | `/deliver:<cmd>` |
| Kill-switch environment variable | `PM_SKILL_NO_ENFORCE` | `DELIVER_NO_ENFORCE`; `PM_SKILL_NO_ENFORCE` still honoured this release, with a one-line note in `hardening.md` |
| Hook and runner user-facing message prefixes | `pm-skill blocked ...`, `pm-skill: ...` | `deliver blocked ...`, `deliver: ...` |
| GitHub repository | `bendusz/pm-skill` | `bendusz/deliver` (GitHub redirects the old URL) |
| Install commands in the README and CHANGELOG top entry | `claude plugin marketplace add bendusz/pm-skill`, `claude plugin install pm-skill@pm-skill` | `... add bendusz/deliver`, `... install deliver@deliver` |
| `AGENTS.md` (this repo), `CONTRIBUTING.md`, `README.md`, `docs/codex-cli-reference.md`, `docs/model-tiering.md`, `docs/prior-art.md`, `plugins/poteto/README.md` and `PORT.md` (the "companion to pm-skill" sentences), `examples/` | old name | new name |
| `scripts/validate.sh`, `.github/workflows/validate.yml`, tests | paths under `plugins/pm-skill/` | `plugins/deliver/` |

## B. What does not change

- The actor-id salt `:pm-skill` in `hooks/lib.mjs`. It keys every existing `pm/actors/` file.
- The `pm/` state directory, `pm-state.json`, `pm-meta`, `pm/log.md`, and `PM_CODEX_STAMP`. "PM"
  is the role, not the product.
- The skill name `project-manager` (the role the plugin plays) and every agent name.
- Historical specs, plans, and CHANGELOG entries below the 0.21.0 heading. They describe the past.
- The `poteto` plugin's own name and contents beyond the two companion sentences.

## C. Migration for installed users

- `README.md` gains an Upgrade note: remove the old marketplace and add the new one
  (`claude plugin marketplace remove pm-skill`, `claude plugin marketplace add bendusz/deliver`,
  `claude plugin install deliver@deliver`), and `PM_SKILL_NO_ENFORCE` keeps working until 0.22.
- Project files a previous version wrote (`AGENTS.md` pointers, `pm/` state, `.claude/rules/pm-state.md`)
  need no change; `/deliver:resume` reads them as before. `references/migrations.md` says so in one
  paragraph.

## D. Release

- Version `0.21.0`; `CHANGELOG.md` top entry `## 0.21.0 - 2026-09-04` describing the rename and the
  migration.
- `bash scripts/validate.sh` ends `validate.sh: OK`; tests green on all three platforms.
- After merge: rename the GitHub repository, then on this machine remove the `pm-skill` marketplace,
  add `bendusz/deliver`, install `deliver@deliver`.
