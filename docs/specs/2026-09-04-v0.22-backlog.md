# v0.22: backlog release

Status: approved by the user on 2026-09-04 ("Do 0.22 now"). Scope: the three items parked for
0.22 by earlier releases. Writing standard: `plugins/poteto/skills/unslop/SKILL.md`.

## A. Drop the old kill switch

- `PM_SKILL_NO_ENFORCE` no longer disables anything. The four hooks read `DELIVER_NO_ENFORCE` only;
  `scripts/tests/helpers.mjs` stops scrubbing the old name; the hook tests assert the new name only.
- `references/hardening.md` and `README.md` say the old name stopped working in 0.22.

## B. Plan template owns delivery, the spec owns intent

- `templates/plan.md.template`: the Stories table loses its `acceptance criteria` column (story
  files own criteria, and `decomposition.md` and the readiness checklist already require them to
  be testable). Columns: `id | title | priority | covers | depends-on | [P]`. Goals and Target users
  stay, with a comment: omit both when `docs/spec.md` exists, because the spec owns them.
- `references/planning-and-signoff.md`: the plan rules no longer say the table's criteria must be
  testable; the `covers` and Traceability rules stay.
- `examples/todo-cli/docs/plan.md` follows the new table and drops Goals and Target users (its spec
  was skipped by the user's request, so keep them; say so in the plan's Source spec line, which
  already does).

## C. Success envelopes carry only what a consumer reads

The wrapper agents relay `runner_status`, `reason`, `scratch_dir`, `actual_files_changed`,
`ignored_files_changed`, `report_path`, `answer_path`, and the model fields; nothing reads the
echoed inputs. Failure envelopes are unchanged (they keep `codex_exit`, `diagnostics_retained`,
and `stderr_path` for diagnosis). Preflight envelopes are unchanged.

- Build and fix completed envelope: `runner_status`, `codex_version`, `model`, `effort`,
  `model_fallback` (when the fallback ran), `actual_files_changed`, `ignored_files_changed`,
  `result` (build never computed `gitignore_rule_needed`; only review does). Dropped: `worktree`, `story`, `mode`, `timeout_seconds`,
  `sandbox`, `diagnostics_retained`, `git_status_short`.
- Review completed envelope: `runner_status`, `report_path`, `codex_version`, `model`, `effort`,
  `gitignore_rule_needed`, `model_fallback` (when it ran). Dropped: `mode`, `scope`, `objective`,
  `codex_exit`.
- Advise and research completed envelope: `runner_status`, `answer_path`, `scratch_dir`,
  `codex_version`, `model`, `effort`, `search_used`, `model_fallback` (when it ran). Dropped:
  `mode`, `stderr_path`, `codex_exit`.
- The builder result schema is unchanged (R47): it is Codex's output contract, not the runner's.
- `docs/codex-cli-reference.md` "Envelope fields per mode" and the codex wrapper agents' bodies
  match; tests that asserted a dropped field assert the same fact another way (the sandbox choice
  through the argv, the changed paths through `actual_files_changed`) or are removed when the fact
  is already pinned.
