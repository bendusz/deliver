# v0.25: the workflow, tightened

Status: approved by the user on 2026-09-08 ("Let's build everything in!"), from the two-model
audit (Claude Fable and Codex gpt-6-astra, both high effort) that produced two recommendations
and two optimisations. Writing standard: `plugins/poteto/skills/unslop/SKILL.md`.

## A. Recommendation: the session hook names the phase (instead of persona files)

Both auditors rejected phase-dependent persona files: anything in `AGENTS.md` or `.claude/rules/`
loads for every session and every subagent, path rules key on file reads, and no phase hook
exists. The skill already loads one reference per phase; that reference is the persona. So:
`hooks/lib.mjs` gains `inspectState(root)` and a `PHASES` map; the session hook prints
`phase: <phase> · load <reference>`; each phase reference opens with an Enter and Leave line;
`SKILL.md` says to trust the hook's line over memory.

## B. Recommendation: a sprint retrospective that feeds `AGENTS.md`

`references/retrospective.md`, `commands/retro.md`, `templates/retro.md.template`. At the
sprint checkpoint, before the pause: a bounded cross-story review of the sprint's first-parent
range (`code-integrity-reviewer` under ~1,500 lines, else `architecture-reviewer`), three
questions answered with evidence from Execution blocks and merge bodies, `AGENTS.md` additions
proposed as a diff and never written unasked, and `docs/retros/sprint-<n>.md` committed with the
accepted lines.

## C. Optimisation: the plan digest is enforced

`require-signoff.mjs` blocks an implementation write, and `build.mjs` refuses to run, when
`plan_digest` is set and differs from `git hash-object docs/plan.md`. Fail-open without a
digest, without a plan file, or when git cannot answer. `/deliver:analyze` also runs again after
decomposition, before the first claim, since its story detections need story files.

## D. Optimisation: one state inspector, and no `AGENTS.md` in dispatch inputs

`node hooks/lib.mjs state [root]` prints `inspectState` as JSON; the session hook renders the
same object; `state-health.md` and `resume-procedure.md` start from it. Seven agent prompts and
the Codex builder prompt stop naming `AGENTS.md` as an input, because every custom subagent
receives it through the `CLAUDE.md` hierarchy and Codex loads it natively;
`instruction-layers.md` states the rule.

## Acceptance criteria

- AC-1: the session hook prints the phase line, and `lib.mjs state` moves through discovery,
  planning, decomposition, implementation, and done as the artifacts change; tests prove both.
- AC-2: a plan whose digest differs from the marker blocks the hook (exit 2) and the runner
  (exit 66); a matching digest, a missing digest, or a missing plan allows.
- AC-3: no agent prompt lists `AGENTS.md` as an input; the Codex prompt says it is already in
  context.
- AC-4: `/deliver:retro` exists, its reference and template exist, and the checkpoint policy
  names it.
- AC-5: version and CHANGELOG at 0.25.0; validate and tests green.
