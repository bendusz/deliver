> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename the marketplace, plugin, directory, command namespace, kill switch, and message prefixes from `pm-skill` to `deliver`, keeping project state and history untouched, released as 0.21.0.

**Architecture:** One mechanical task done with `git mv` plus a careful sed over the current files only, then a hand pass over the places sed cannot judge (the salt, history, the kill switch that honours both names). One release task.

**Spec:** `docs/specs/2026-09-04-v0.21-rename-deliver.md`

- Branch `feat/v0.21-rename-deliver`. Commit after every task. Never push.
