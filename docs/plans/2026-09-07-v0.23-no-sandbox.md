# v0.23 Codex without a sandbox Implementation Plan

**Goal:** Run every Codex mode with `sandbox_mode="danger-full-access"` and the user's own Codex
config, keeping the after-run audit as the guard, released as 0.23.0.

**Spec:** `docs/specs/2026-09-07-v0.23-no-sandbox.md`

## Global Constraints

- Runtime code is Node ESM only. Hooks are untouched.
- `bash scripts/validate.sh` ends `validate.sh: OK` and `node --test plugins/deliver/scripts/tests/`
  is green at the end.
- Branch `feat/v0.23-no-sandbox`. Never push.

### Task 1: Runner

- [x] `lib/argv.mjs`: `lockedExecArgs` drops `--ignore-user-config`, `--strict-config`,
  `mcp_servers={}`, and the unconditional `web_search="disabled"`; adds
  `-c sandbox_mode="danger-full-access"`; gains `searchOff` for research `--search off`.
- [x] `lib/preflight.mjs`: `BUILD_FLAGS` and the renamed `EXEC_FLAGS` drop `--sandbox`,
  `--ignore-user-config`, `--strict-config`; `REVIEW_FLAGS` drops the last two.
- [x] `modes/build.mjs`: no `sandboxArgs` or `sandboxConfig`, one `policy()`, no `WIN`, the prompt no
  longer forbids the network.
- [x] `modes/advise.mjs` and `modes/review.mjs`: no `--sandbox read-only`; `EXEC_FLAGS`.

### Task 2: Tests

- [x] `codex-run.test.mjs`: the shared-flag test, build 5, build 15, build 23, the review and advise
  argv tests, and the two hostile-config tests assert the new posture; the "no exec ran" probes
  match `^exec --ignore-rules`.

### Task 3: Docs and release

- [x] `docs/codex-cli-reference.md`, `README.md`, `commands/codex-review.md`,
